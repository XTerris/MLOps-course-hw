# Источник данных

## GitHub Issues

Данные получены из публичного GitHub REST API. Сборщик использует issues
Python-репозиториев, созданные в период с 1 января 2024 года по 31 декабря 2025
года. Pull requests исключаются по полю `pull_request`.

Происхождение каждой строки сохраняется в идентификаторе
`github:<owner>/<repo>#<number>`, а поле `topic` содержит `<owner>/<repo>`.
Исходный заголовок и body объединяются в user-сообщение. Assistant-сообщение —
одна из четырёх канонических меток: `bug`, `documentation`, `feature`,
`question`.

## Лицензии

Перед сбором проверяется SPDX-идентификатор репозитория. Разрешены только MIT,
Apache-2.0, BSD-2-Clause, BSD-3-Clause и ISC. Репозитории без распознанной или
с иной лицензией в набор не входят.

## Повторный сбор

Параметры API, период, mapping labels, список лицензий, лимит на репозиторий и
размеры версий находятся в `params.yaml`. Авторизация необязательна; при её
использовании `GITHUB_TOKEN` читается только из окружения. Сборщик обрабатывает
pagination, `Retry-After` и `X-RateLimit-Reset`.

Зафиксированные версии восстанавливаются через DVC и не требуют повторного
обращения к GitHub. Новый сбор может отличаться побайтно, если владельцы
репозиториев изменили или удалили issues либо labels.
