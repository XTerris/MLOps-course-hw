# ДЗ 6–7: эксперименты и оценка GitHub Issues

Продолжение ДЗ 4–5 в общем репозитории. Условие и исходная заготовка сохранены в `mlops26-hw6-7/`; рабочий код расположен в текущем каталоге. Лекции: `lecture6.html`, `lecture7.html`.

Python 3.12 и окружение `.venv` общие для всех ДЗ. Из корня: `uv sync --frozen`. В `HW 6-7` команды Makefile используют корневой lock-файл; неизменённые проверки также находят проект в родительском каталоге.

## Воспроизведение

1. Установить Docker с Compose и обеспечить доступ к закреплённой базе Qwen3-0.6B. Сервер: http://127.0.0.1:5006, compose project `mlops-hw6`.
2. Восстановить тензоры ДЗ 4 через DVC; скопировать `train.pt`, `val.pt` в `data/tokenized/` побайтово. SHA-256 указаны в `docs/data-lineage.json`.
3. Восстановить `data/eval` командой `uv run --project .. --frozen dvc pull data/eval.dvc`. Remote `local` находится в корневом `dvc_remote/` и не доступен из одного Git clone. Для преподавателя набор приложен отдельно; распаковать каталог `data/eval` из приложения в эту папку. Для аудита происхождения нужны также исходные данные ДЗ 3–4.
4. При наличии исходных JSONL данные оценки воспроизводит `PYTHONPATH=. uv run --project .. --frozen python tools/prepare_eval.py`. В скрипте закреплены 52 ID и обоснования разметки. Индекс включает все исходные train-вопросы, в том числе строки, потерявшие supervised-токены при обрезке.
5. Выполнить `make check-eval`, `make up`, `make sweep`, `make report`, `make candidate`, `make baseline-init`, `make evaluate`, `make eval`, `make check-negative`.
6. Только после PASS выполнить `make promote`. При отказе сохранить его и пропустить продвижение. Затем `make check-storage` и `make check-all`. `make baseline-update` не входит в обязательный запуск: обновление точки отсчёта всегда отдельное действие.

Если исходный baseline уже существует, повторно `baseline-init` не выполнять. Если сохранён законченный sweep и хеши входов совпадают, не запускать обучение повторно. Протокол и пороги после получения ответов не ослаблять.

## Сдача

`docs/conclusion.md` — единый отчёт; `docs/defects.md` — причины и исправления; `docs/comparison.csv` — выгрузка MLflow. Сырые ответы, метрики и гейты сохраняются в `metrics/` и Git. Веса, тензоры, volumes, `.venv` и видео исключены из Git. Наборы оценки версионируются DVC и дополнительно приложены к сдаче. Отпечаток исходных тестов: `c42ac7788026`.
